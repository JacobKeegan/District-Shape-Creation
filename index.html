Project summary

There are many district types in the state of New York, such as Town/City, County, Congressional, Senate, Assembly, and Election districts. Election districts are the units that these other districts are made up of. In other words, an Election district cannot cross the borders of any of these other districts. In brief, everyone within an election district has the same polling place. The goal of this project is to create geometry data for Election districts.
